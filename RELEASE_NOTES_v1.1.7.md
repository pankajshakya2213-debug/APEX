# APEX v1.1.7

## What's New
- Settings now has a complete in-app update flow.
- When a new GitHub release is available, APEX shows Download Update directly inside the app.
- Download progress is shown in the Settings update panel.
- After download completes, Install & Restart upgrades APEX to the new version.

## Improved
- Update checking, downloading, and installing now return clearer status messages inside APEX.
